# 九牛核 · EV Riders Club

九号、极核、小牛电动摩托车与电动轻便摩托车的独立资料库。V2 整理中国大陆公开车型、具体配置、参数、价格依据和图片来源，资料快照截至 **2026-10-28**；不收录电动自行车。沿用初版的界面，视觉重设计留待 V3。

## 本地运行

Node.js 20 及以上，推荐 22。无第三方运行依赖，无需 npm install。

```sh
npm run catalog
npm run dev
```

访问 [本地预览](http://localhost:5173)。指定端口：`npm run dev -- --port 3000`。

```sh
npm run check
npm run build
npm run preview
```

构建生成 `dist/` 静态网站，同时更新根目录 `preview.html`。离线双击 `preview.html` 时必须保留相邻的 `public/` 文件夹，图片以本地文件加载。部署需上传完整 `dist/`，支持 GitHub Pages 子路径。

## 内容与功能

- 三品牌目录按车型名称、年款和配置分别记录；搜索支持型号、品牌、别名。
- 可按车辆类别、全价格段、销售状态筛选；未知价格单独可选。默认显示全部状态，官网列售、库存、在售待核、历史车型分别标记。
- 价格从低到高／高到低排序，未知价格放在最后；上市指导价、官方公开价和渠道价保留不同标签。
- 最多三条配置横向对比，支持只看差异；区分额定与峰值功率，续航保留测试条件。
- 多图缩略图、前后切换、放大查看，图片附来源和配置匹配说明。支持键盘和手机滑动。
- 收藏与对比保存在当前浏览器；选车问答按已知预算、车辆类别和公开配置匹配。
- 核验范围弹窗列出候选、排除项及资料缺口，可下载结构化目录 JSON。

## 资料口径与当前缺口

本库覆盖已列明的公开目录与报道，**不承诺市场绝对无遗漏**。官网仍展示某车不等于当地门店有库存；“官网列售”表示官方有购买入口或相应列售依据。在售无法确认的记录继续保留并注明状态。车型数按品牌、营销名称与年款去重，配置记录数单独统计，不代表工信部公告型号数。

每条配置的图片目标为 **至少 3 张不同实拍**。官方渲染、类型待核的图片不计入实拍达标数量；同外观版本共用图片会注明适用关系。当前仍存在缺图版本，不能把“已有图库”理解成“每台车三张实拍已齐”。逐版本进度见 [资料覆盖报告](research/reports/coverage.md)。

价格不是实时成交报价。尚未确认准确版本、所含电池和购买条件的价格留空；发布时的指导价明确标为上市指导价，促销价与补贴不伪装成标准价。未知参数保持未知，V1 六条演示数据和主观综合分已移除。资料矛盾、类别细分待核等说明保留在对应记录中。

图片采用本地文件并保留原始来源、图片类型和匹配说明。收录不改变原作者权利；转载或另作商业用途前需单独确认授权。首页原创 SVG 仅作风格示意。

## 数据维护

编辑 `data/catalog/<brand>.json` 后运行 `npm run catalog`。生成的 `src/catalog.js` 与 `public/data/catalog.json` 不应手动编辑。

- [数据约定](docs/v2-data-contract.md)：字段、证据和图片验收口径。
- `research/reports/`：三品牌采集说明与合并覆盖报告。
- `research/sources/`：采集的页面快照和研究摘录；与车型无关的小程序标识经脱敏处理，不随网站部署。
- `public/images/catalog/`：有来源记录的本地车型图片。
- `scripts/catalog-lib.mjs`：来源、类型、字段引用、图片文件及重复校验。
- `src/data.js`：前端显示格式和筛选口径。
- `src/main.js` / `src/modals.js`：目录、对比、问答及图库。

`npm run check` 检查脚本、来源快照、数据引用和图片文件。新采集的来源快照提交前运行 `npm run sanitize:sources`，移除与车型证据无关的微信小程序 App ID；`npm run check:sources` 发现未脱敏标识时会报错，且不打印标识值。这是针对已知标识的检查，不能替代完整的密钥扫描。缺价格／缺实拍作为公开缺口保留；非法字段、缺少数值参数证据、重复图片和快照之后的来源会阻止校验通过。

## 在线部署

构建命令 `npm run build`，静态资源目录 `dist/`，无需后端、数据库或业务密钥。已有 Cloudflare Workers、Vercel 与 GitHub Pages 配置，操作见 [上线说明](deploy/README.zh-CN.md) 和 [GitHub Pages 说明](deploy/GITHUB-PAGES.zh-CN.md)。

V2 内容预览通过 GitHub Pages 发布：[打开九牛核](https://jarvanszzz.github.io/jiuniuhe/)。`main` 为发布分支，开发分支的更新合入并推送到 `main` 后自动部署。当前仍需继续补齐车型资料、价格与实拍，线上预览不代表内容库已经全部验收。各免费托管域名在中国大陆的可达性仍需在实际网络验证。
